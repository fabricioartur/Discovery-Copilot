# Sample Discovery Notes

Customer: Northstar Retail Group

Northstar is a mid-sized retail company with stores across three regions. The
operations team is trying to reduce manual work in customer support and improve
visibility into order exceptions.

Current environment:

- CRM: Salesforce
- ERP: SAP
- Customer support: Zendesk
- Identity provider: Microsoft Entra ID
- Cloud footprint: mixed AWS and on-premises workloads
- Data warehouse: Snowflake

Business goals:

- Reduce average support handling time
- Improve self-service for order status questions
- Give store managers faster access to operational information
- Reduce manual spreadsheet reporting

Pain points:

- Support agents switch between Salesforce, SAP, and Zendesk
- Order exception reporting is mostly manual
- Store managers depend on weekly reports
- Engineering is concerned about access control and auditability

Discussion notes:

- Customer is interested in an AI assistant for support agents
- They want API-first integration and reusable services
- Security team must approve any customer-data use
- Timeline target is a pilot in the next quarter
- Budget has not been confirmed
- Data residency requirements were not discussed
- Expected user count was not confirmed
