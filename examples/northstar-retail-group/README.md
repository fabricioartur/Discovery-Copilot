# Northstar Retail Group Sample Scenario

This folder contains a complete fictional enterprise customer scenario for
Discovery Copilot.

Northstar Retail Group is a large retail company with 420 stores, e-commerce
operations, support teams, and legacy systems across Latin America. The scenario
is designed to show how Discovery Copilot can transform raw discovery notes into
structured pre-sales documentation.

## Contents

- `discovery-meeting-notes.md` - realistic raw discovery notes
- `generated-output/` - sample Markdown reports generated from the scenario
- `consolidated-sample-report.md` - single executive-style report
- `diagrams/architecture.svg` - architecture diagram
- `data/discovery-score-chart.csv` - chart-ready score data
- `data/discovery-score-chart.json` - JSON score data for dashboards

## Suggested Demo Flow

1. Review the raw meeting notes.
2. Run Discovery Copilot against the input file.
3. Compare generated reports with the sample output files.
4. Show the consolidated report as an internal handoff artifact.
5. Use the Mermaid diagram and score data to demonstrate visual reporting.
