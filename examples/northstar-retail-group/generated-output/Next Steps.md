# Next Steps

## Priority 1 - Confirm Pilot Scope

- Select the first support workflow, such as order status and refund assistance.
- Confirm Brazil and Mexico pilot users by role.
- Define what the assistant can read, recommend, and update.

## Priority 2 - Validate Integration Requirements

- Review Salesforce, OMS, ERP, Zendesk, and MuleSoft integration paths.
- Identify missing APIs and SOAP adapters.
- Confirm source of truth for order, customer, and loyalty data.

## Priority 3 - Complete Security and Compliance Review

- Define redaction, retention, audit, and role-based access requirements.
- Clarify LGPD and country-specific privacy obligations.
- Confirm whether data residency constraints affect architecture.

## Priority 4 - Baseline Success Metrics

- Capture current average handling time, escalation rate, backlog, and CSAT.
- Define pilot acceptance thresholds.
- Decide how adoption and answer quality will be measured.

## Priority 5 - Schedule Technical Workshop

- Include enterprise architecture, security, support operations, regional IT,
  integration owners, and data owners.
- Produce a pilot architecture, risk register, and implementation plan.
