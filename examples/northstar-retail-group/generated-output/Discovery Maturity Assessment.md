# Discovery Maturity Assessment

## Classification

Intermediate

## Rationale

The discovery captured strong business context, a meaningful stakeholder map,
clear pain points, initial requirements, and several risk areas. The team
understands the customer's fragmented architecture and has identified a plausible
AI-assisted support use case.

The discovery is not yet Advanced because several enterprise-critical details
remain unresolved: SLA, data residency, budget ownership, pilot user count,
model governance, integration readiness, and disaster recovery expectations.

## Recommendations To Reach Advanced

- Confirm pilot scope and success metrics in writing.
- Validate API availability for OMS, Salesforce, SAP, and Oracle systems.
- Complete a data classification and redaction review.
- Define governance for knowledge sources and AI recommendation review.
- Establish a phased rollout plan by country, role, and workflow.

## Recommendations To Reach Enterprise Ready

- Create a production architecture and security design.
- Define operational runbooks and incident response ownership.
- Approve data retention and audit log policies.
- Implement ongoing quality monitoring.
- Document expansion criteria beyond Brazil and Mexico.
