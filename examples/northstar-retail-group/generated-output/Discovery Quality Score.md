## Why Points Were Deducted

- Pilot user count and budget ownership were not confirmed.
- SLA, disaster recovery, and data residency requirements remain open.
- Security governance was discussed but not fully defined.
- Integration feasibility is still uncertain for OMS, SAP, and Oracle fields.
- Success metrics were directional but not baselined.
- Knowledge article quality is unknown.

## Missing Information

- Country-by-country privacy requirements.
- Exact source of truth for customer identity and loyalty data.
- Required audit fields and retention periods.
- Pilot acceptance criteria.
- Zendesk migration dependency map.

## Improvements Required

- Run a focused technical workshop.
- Build a pilot use-case matrix.
- Confirm API availability and integration owners.
- Establish security and data governance requirements.
- Baseline operational metrics before pilot launch.
